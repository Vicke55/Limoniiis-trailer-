## 1. About the addon

GeoFS A350 Startup is a userscript for GeoFS designed to make the Airbus A350 startup experience more immersive and detailed.

Key features that could be shown:
- An overhead panel with images following the startup sequence.
- Two startup options: APU and external power (EXT).
- Interactive checklists with step-by-step instructions.
- A GROUND menu for connecting and disconnecting external power.
- An ENG START panel with engine-start and engine-shutdown sequences.
- Cockpit clicks, cabin sounds, seatbelt chimes and fan sounds.
- A separate overhead window.
- Procedures covering cockpit preparation, engine start, flight preparation, landing and shutdown.

The trailer should showcase the actual addon and its interface, combined with suitable GeoFS A350 footage. The overall style should be cinematic, professional and aviation-focused.
